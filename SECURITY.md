# Security Policy

Report security issues **privately**. Do not open a public GitHub issue for leaked tokens, webhook secrets, or a live exploit.

## How to report

1. Open [@BlinkboardBot](https://t.me/BlinkboardBot)
2. Send `/support` plus what you found (URL, impact, how to reproduce)
3. Or use GitHub private vulnerability reporting on this repository

We will not ask you to send secrets in a public channel or group.

## Scope

In scope: the public site (`blinkboard.pages.dev`), the Worker, the Telegram bot, and this repository.

Out of scope: other products on this GitHub account, and noisy unauthenticated scanning of the live webhook.

## What we already run

GitHub CodeQL, Gitleaks, Dependabot, and secret scanning on this repo.
